## 3. Bugs found & fixed during live validation

| Bug | Root cause | Fix |
|-----|-----------|-----|
| UiPath token 302 → `/portal_/unregistered` | global `identity/connect/token` URL is not valid for external apps | org-scoped `…/{org}/identity_/connect/token` (note `identity_`), auto-built in `executor.py` / `validate_credentials.py` / `discover_uipath.py` |
| UiPath token 400 `invalid_scope` | app not granted `OR.AuthAPI` | new `UIPATH_TOKEN_SCOPE` setting (default `OR.Folders.Read`, verified live) |
| Gemini tests silently dropped | live models emit dict/list step `value`; schema is str-typed | `_transform_tests` now JSON-serializes non-string step fields |
| XAI "key format unrecognized" warning with a valid key | fired when `openai` package import failed, not on format | distinct warnings; broken local `openai 3.3.1` install repaired (`httpx2`, `jiter`) |
| `UIPATH_CLIENT_SECRET` leading space / unquoted `#`,`$` | dotenv parsing hazards | value quoted in `.env` |
| XAML generation crash `cannot serialize None (type NoneType)` | live AI output includes `null` step fields; ElementTree can't write `None` attributes | `xaml_generator.generate_xaml` coerces null/non-string step fields to strings |
| Probe intake `ReadTimeout` after 30s | pipeline runs inline (Gemini calls take ~20–70s) | `live_pipeline_probe.py` intake timeout raised to 180s |
| Heal-proposal parse failure (logged, non-fatal) | Gemini truncated the heal JSON at the output-token limit | handled gracefully by the pipeline; noted as a known limitation |
| Server started with `DEMO_MODE=True` despite `.env=false` | leaked `DEMO_MODE` env var in the launching shell overrides `.env` | launcher strips leaked vars (`_live_server.py` pattern); verify `/` health shows `demo_mode: false` before probing |
